OFFICIAL EXAM OBJECTIVES

Blueprint DCAI v1.0

Objetivos preservados em inglês, como publicados no documento Cisco 300-640. Seções e subtópicos organizados para acompanhamento individual, com notas e autoavaliação.

O documento Cisco define as seções 1.0 a 4.0, cada uma com objetivos numerados. Itens com letras (por exemplo, 3.1.a) são acompanhados separadamente; objetivos sem letras, como 2.1, são tratados como um único item.
